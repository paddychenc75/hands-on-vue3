# 综合测验

测验有 60 题。按下面的步骤完成：

1. 选择一个阶段，或选择“全部”。
2. 每题选择一个答案。
3. 阅读解析。
4. 答错时，点击解析中的链接，复习对应章节。

页面保存你的成绩。登录 Claude 后，成绩和学习进度保存在你的账号中，换设备也能看到。点击“重新作答”清除成绩。
